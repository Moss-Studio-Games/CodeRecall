# CodeRecall

### Set up
<ol>
    <li>Download from Godot (AssetLib section in the top row)</li>
    <li>Enable from: Project -> Project Settings... -> Plugins</li>
    <li>Find the new tab that appears on the right (where Inspector, Signals, Groups live)</li>
    <li>Specify your project folder and wait a couple seconds</li>
</ol>

### Use
<ul>
    <li>Search your code with the search bar</li>
    <li>Customize the higlight color</li> 
    <li>Copy part of the function -> Click Hold + Drag</li>
    <li>Copy the entire function -> Click</li>
    <li>Copy the entire script -> Shift + Click</li>
</ul>
