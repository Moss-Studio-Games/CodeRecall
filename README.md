# CodeRecall

### Set up
<ol>
	<li>Download from Godot (AssetLib section in the top row)</li>
	<li>Enable from: Project -> Project Settings... -> Plugins</li>
	<li>Find the new tab that appears on the right (same as Inspector and Signals)</li>
	<li>Specify your project folder</li>
	<li>IMPORTANT: it will take a few seconds to retrieve all scripts, just wait</li>
</ol>

### Use
<ul>
	<li>Search your code with the search bar</li>
	<li>Customize the higlight color</li> 
	<li>Copy part of the function -> Hold Left Click + Drag</li>
	<li>Copy the entire function -> Left Click</li>
	<li>Copy the entire script -> Shift + Left Click</li>
</ul>
